# INF209 Basis Data — Week 05

## Building the SmartEdu Schema

Interactive learning material for **INF209 Basis Data**.

Pada Week 05, mahasiswa mengimplementasikan relational schema **SmartEdu** menjadi tabel database menggunakan **Oracle SQL DDL**.

- ERD to Relational Schema
- Oracle Schema Preparation
- SQL DDL
- `CREATE TABLE`
- Oracle Data Types
- Primary Key & Foreign Key
- `NOT NULL`, `UNIQUE`, and `CHECK`
- Table Creation Order
- Schema Verification
- DDL Debugging
- `ALTER TABLE`

### SmartEdu Tables

`STUDENT` • `LECTURER` • `COURSE` • `SEMESTER` • `CLASS` • `ENROLLMENT`

## 📖 About This Module

Week 05 focuses on implementing the **SmartEdu relational schema** into an actual database structure using **Oracle SQL Data Definition Language (DDL)**.

In previous weeks, students learned how to identify entities, attributes, relationships, cardinalities, Primary Keys, and Foreign Keys.

Now we move from:

**ERD → Relational Schema → Database Implementation**

The main question for this week is:

> **How do we transform a database design into an executable database structure while maintaining data integrity?**

---

## 🎯 Learning Outcomes

After completing this module, students should be able to:

1. Translate a relational schema into database tables.
2. Determine table creation order based on Foreign Key dependencies.
3. Select appropriate Oracle data types.
4. Create tables using `CREATE TABLE`.
5. Define Primary Keys and Foreign Keys.
6. Apply database constraints.
7. Verify database structures.
8. Identify and debug DDL errors.
9. Modify an existing database structure using `ALTER TABLE`.
10. Explain how database constraints support data integrity.

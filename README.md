## 🎯 Learning Outcomes

Setelah menyelesaikan modul ini, mahasiswa mampu:

- Menerjemahkan ERD menjadi relational schema.
- Menentukan table creation order.
- Menggunakan Oracle SQL DDL.
- Membuat tabel dengan `CREATE TABLE`.
- Menentukan Primary Key dan Foreign Key.
- Menggunakan `NOT NULL`, `UNIQUE`, dan `CHECK`.
- Memverifikasi database structure dan constraints.
- Melakukan debugging DDL.
- Memodifikasi struktur menggunakan `ALTER TABLE`.
